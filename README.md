# Две пекарни в Грузии

Статические сайты двух выдуманных пекарен на русском, английском и грузинском.

| Папка | Пекарня | Ссылка |
|---|---|---|
| `tbilisi/` | «Бетлеми», у лестницы Бетлеми в Старом Тбилиси | https://vbzzzr.github.io/bakery-georgia-site/tbilisi/ |
| `batumi/` | «Цвима», пекарня имени дождя в Батуми | https://vbzzzr.github.io/bakery-georgia-site/batumi/ |

Языки: русский — `index.html`, английский — `en/`, грузинский — `ka/`.

Пекарни, контакты, цены и часы работы выдуманы. Фотографии взяты с Wikimedia Commons;
авторы и лицензии указаны внизу каждого сайта и в `*/assets/credits.json`.
Шрифты сайта «Цвима» распространяются по SIL Open Font License (`batumi/assets/fonts/LICENSE.txt`).
